## 🧠 About Me

Backend developer based in Mexico with an unconventional path: I started in **Psychology**, switched to **Systems Engineering**, and never looked back. A childhood fascination with tech — and a certain 90s hacker movie — turned into a career building APIs, logistics systems, and backend infrastructure.

Currently at **Envíame** designing carrier assignment engines and real-time tracking systems that power e-commerce logistics across Latin America.

- 🔭 Backend Developer at [Envíame](https://enviame.io/)
- 🎓 Master's in Software Development — Universidad Politécnica de Tulancingo *(2025–2027)*
- 🌱 Currently deepening: **NestJS, Bun, system design**
- 💬 Ask me about **Node.js, Python, APIs, Docker, GCP**
